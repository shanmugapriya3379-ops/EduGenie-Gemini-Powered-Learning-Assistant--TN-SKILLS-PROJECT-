EduGenie - Google Gemini Powered Learning Assistant
**Team ID: SWTID-2026-5473 | TN Skills Project**

An AI-powered personal learning assistant that helps students understand concepts, clear doubts, and learn at their own pace using Google Gemini.

🎥 Demo Video
https://youtu.be/YOUR_LINK_HERE

✨ Features
- Concept Explanation in Simple Tamil & English
- Instant Q&A Doubt Clearing
- Auto Quiz Generation
- Content Summarization
- Personalized Learning Path

🛠️ Tech Stack
- Python
- Google Gemini API
- Streamlit / Flask
- HTML, CSS

👩‍💻 Team Members
- M. Abhinaya
- Shanmugapriya

🚀 How to Run
pip install -r requirements.txt
streamlit run main.py

📂 Project Files
- main.py - Main application file
- requirements.txt - Dependencies
- README.md - Project Documentation
